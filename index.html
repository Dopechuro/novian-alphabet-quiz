Novian Alphabet Quiz

Objective

Learn the Novian alphabet by playing a quiz type learning tool for memorizing the Nova characters.

How to Learn

Don't worry about making mistakes. Start making guesses, even if you don't know the characters. The correct answer will be revealed after each guess. Keep trying until you get the right answer.

Proficiency Level

Adjusts the learning curve. Lower levels repeats characters you get wrong more to reinforce your memory.

Quiz Mode & Quiz Type

Write: Use your keyboard to type the matching character (recommended for PC users).
Standard vs Combined: Write the correct answer for one or three combined characters.

Select: Choose the correct answer from three multiple-choice options (recommended for mobile users).
Standard vs Reversed: Translate Novian, or to Novian.

Font Options

Choose the visual style of the Nova characters you want to study: Print or Cursive.

Learn/Read

Select which set of characters to learn or read.

Reading Practice

Test your fluency level by reading story snippets from the game.
